# Домашнее задание к работе 8

## Условие задачи

Вычислите \(1^K + 2^K + \dots + N^K\) для заданного пользователем целого \(N\) и \(K\).  
Чтобы избежать целочисленного переполнения, вычислять как вещественное.

## 1. Алгоритм и блок-схема
### Алгоритм решения
1. **Начало**
2. Задать исходные данные: 
   - \(N\) (целое число элементов)
   - \(K\) (целая степень)
3. Инициализировать переменную суммы вещественным числом:
   `sum = 0.0`
4. Выполнить цикл **Повторение** для переменной \(i\) от 1 до \(N\) включительно с шагом 1:
   - Вычислить текущее слагаемое: `pow((double)i, (double)K)`
   - Прибавить полученное значение к `sum`
5. Вывод результата:
   Вывести значение `sum`
6. **Конец**

## 2. Реализация программы

```c
#include <stdio.h>
#include <math.h>

int main() {
    int N, K;
    double sum = 0.0;

    // Ввод данных от пользователя
    printf("Введите целое число N: ");
    if (scanf("%d", &N) != 1) {
        printf("Ошибка ввода N.\n");
        return 1;
    }

    printf("Введите целое число K: ");
    if (scanf("%d", &K) != 1) {
        printf("Ошибка ввода K.\n");
        return 1;
    }

    // Цикл «Повторение» для вычисления суммы
    for (int i = 1; i <= N; i++) {
        sum += pow((double)i, (double)K);
    }

    // Вывод результата
    printf("Сумма равна: %.2lf\n", sum);

    return 0;
}
```
